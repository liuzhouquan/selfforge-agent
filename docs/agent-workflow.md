# Coding Agent 协作流程（兼容入口）

当前完整流程已集中到 [SDD](./SDD.md)，从该文件即可领取任务、理解范围、实施、验证和交接。本页不再维护第二套任务流程或当前状态。

1. [确认现场与领取一项任务](./SDD.md#2-开工与选择任务)：核对 Git/开放 PR，保护未知改动，各自使用拥有的 worktree。
2. [读取具体任务规格](./SDD.md#4-下一阶段里程碑与任务队列)：登记 Owner/base/分支；范围、前提和验收在同一节维护。
3. [保持工程约束](./SDD.md#3-实际架构与必须保持的约束)：沿已有 Runtime/Runner 扩展，只查相关模块的详细契约。
4. [回填验收证据](./SDD.md#5-验收追踪与执行记录格式)：测试节点、命令、真实 SHA、CI 和未验证项逐条对应。
5. [验证与交付](./SDD.md#6-安装与验证门槛)：区分 mock、Host、Docker 与真实模型；使用已有授权。
6. [交接与合并](./SDD.md#7-审查合并与交接)：保留原提交，只合并已审查且准确 head CI 通过的结果，留下一个具体下一步。

可复制的接手 prompt 见 [SDD 末节](./SDD.md#9-可直接复制的接手指令)。旧任务模板和 Backlog 仅供历史追溯，不需要先阅读它们或再创建重复任务文件。
