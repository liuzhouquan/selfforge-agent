# 工作区与测试证据绑定

通用 Coding 的 `completed` 必须同时具备非空 JUnit 成功、匹配当前工作区的内容指纹和非空最终答复。外部编辑器、其他进程或 Host 测试自身的写入，也可能使旧测试证据失效。

## 执行与恢复

1. `run_tests` 之前先持久化撤销旧证据，再扫描工作区。
2. 调用既有 JUnit Runner；仅当测试通过且前后指纹相同时，保存新的成功证据。
3. 后续模型请求前重新校验已有证据，使预算提示反映当前验证状态。
4. 模型返回最终答复后再检查一次，覆盖模型调用期间的外部改动。指纹不匹配时返回 `unverified`，需要重新测试。
5. 恢复会话时，在原执行模式/镜像绑定通过后检查保存的指纹；不能用其他路径下内容相同的工作区代替原工作区。

新的私有会话事件带 `evidence=junit-workspace-v2` 与 `workspace_sha256`。没有有效指纹的新成功事件不能写入。旧 `junit-v1` 和更早的布尔成功事件仍可读取，但不能恢复完成证据；续跑时重新调用 `run_tests`。历史任务记录保留当时状态，不会成为持续监控当前文件的实时状态。

这项检查由共用 `CodingAgent` 完成，CLI/Web 使用同一执行路径。直接调用 Runner/ToolRegistry 仍报告当次 JUnit 结果；它们本身不宣称通用任务已经完成。PR Repair、差异测试与独立评测保留各自的验证条件。

## 指纹包含什么

`runtime/fingerprint.py` 使用 SHA-256，包含工作区绝对路径、相对条目名、类型、权限、普通文件长度/内容，以及符号链接目标字符串。读取内容，不依赖 mtime 缓存；同长度且恢复时间戳的源码修改仍会失效。空目录、新文件、删除、重命名和 chmod 也会改变指纹。

目录与文件通过目录描述符及 `O_NOFOLLOW` 打开，符号链接不解引用；不读取指向工作区外的文件。扫描时检测条目身份/元数据变化，不完整扫描不能保留成功证据。错误与公开轨迹只包含固定原因，不包含源码、原始 OS 错误、文件清单或工作区路径；哈希只保存在 mode-0600 会话中。

扫描与 Docker 暂存共享排除规则：`.git`、`.venv`、`.env`/`.env.*`、`.local`、`.selfforge`、`.workspaces`、`.aws`、`.ssh`、`.npmrc`、`.pypirc`、`.netrc`、`node_modules`、`__pycache__`、`.pytest_cache`、`.ruff_cache`。这些路径的内容不属于指纹；pytest/Python 生成缓存不会持续撤销证据。Docker 暂存也忽略这两类 pytest/Ruff 缓存。

## 限制与失败处理

- 最多 8,000 个未排除条目、64 MiB 普通文件内容和 128 层目录；不读取 FIFO、设备等特殊条目。
- 每次扫描最多 10 秒，同时受任务剩余时间限制；扫描目录/内容时检查取消与截止时间。超限、不可读或扫描中变化会阻止建立证据，已有证据会失效。超时/取消保持对应任务状态。
- 不按 `.gitignore` 自动排除普通项目文件；Host 大仓库也受上述限制。无法获得完整指纹时不能宣称完成，应缩小工作区或移出不需要的生成文件。
- 这是有界内容观察，不是文件系统原子快照或工作区锁。检查结束后的竞态、恰好在两次观察之间恢复原样的改动、断电事务一致性仍不在保证范围内。
- 不追踪符号链接目标的内容、Host 外部依赖、排除路径、环境变量或后台进程。Docker 的不可变镜像绑定继续生效；Host 仍需显式信任。
- 不防恶意测试伪造 JUnit，不证明测试覆盖充分。正式评测仍需独立可见/隐藏测试；本轮没有新增模型成功率数据。

## 验证

旧实现上的定向复现：**7 failed / 2 passed**。失败涵盖外部源码/测试/新增文件/删除/权限变化、最终模型调用期间写入及 Host 测试改写源码；两个成功对照是未修改/缓存变化与重新测试。

```sh
uv run --no-sync pytest -q tests/test_workspace_evidence.py tests/test_workspace_fingerprint.py
uv run --no-sync pytest -q
uv run --no-sync ruff check .
```

新增 Docker 集成用例执行真实测试获得成功证据，再从外部修改源码，验证续跑降为 `unverified`，独立 Docker 测试确认失败。缺少 daemon/镜像时会明确跳过；完整本地与 CI 结果以交付 PR 为准。

本地完整结果：**274 passed / 11 skipped**，231.86 秒；一条现有 Starlette/httpx 弃用警告，Ruff 与 Git 空白检查通过。跳过项均需 Docker；Desktop 引擎启动后 WSL socket 仍不可访问，不能称为本机隔离验证通过。远端 CI 会构建镜像并运行全部 Docker 集成用例，结果见对应 PR。
